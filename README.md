# پروژه نهایی کنگرو ۲
#### عسل باقرنیا

# مراحل اجرای پروژه

برای اجرای این پروژه دو روش وجود دارد
۱. روش اول استفاده از داکر هست (روش پیشنهادی)
۲. روش دوم راه اندازی دستی پروژه هستش

## روش اول - استفاده از داکر
برای استفاده از داکر کافیه دستور
```bash
docker compose -d --build
```
رو اجرا کنید تا کانتینرها خودکار ساخته و اجرا شوند.
پس از اجرا شدن شما میتوانید از طریق آدرس `http://127.0.0.1` به پروژه دسترسی داشته باشید و استفاده کنید.

## روش دوم - راه اندازی دستی
در این روش ما دو بخش داریم که باید اجرا بشوند
بخش اول فرانت اند و بخش دوم بک اند

برای راه اندازی بخش اول - اول از همه نیاز داریم که پیش نیاز های پروژه فرانت اند را نصب کنیم به این منظور اول از همه وارد پوشه فرانت اند میشویم
```bash
cd frontend
```
بعد از اینکه وارد پوشه فرانت اند شدیم باید پیش نیاز های پروژه را نصب کنیم
```bash
npm install
```
قبل از اجرای پروژه نیاز است تا فایل .env را ساخته و تغییر دهیم
در فایل `.env` باید مقدار `VITE_API_URL` را به آدرس بک اند تغییر دهیم که به طور پیشفرض هست `http://127.0.0.1:5000/api/v1`

بعد از نصب پیش نیازهای پروژه کافیست پروژه را درحالت توسعه اجرا کنیم
```bash
npm run dev
```

حالا که فرانت اند راه اندازی شد میریم سراغ بخش دوم

برای راه اندازی بخش دوم یعنی بک اند اول وارد پوشه مورد نظر می شویم
```bash
cd backend
```

بعد از اینکه وارد پوشه بک اند شدیم باید یک محیط مجازی برای پروژه ایجاد کنیم
```bash
python3 -m venv .venv
```
و بعد از ساخت محیط مجازی باید به آن دسترسی اجرا و درنهایت فعالش کنیم
```bash
chmod +x .venv/bin/activate
source .venv/bin/activate
```

بعد از فعال سازی محیط مجازی پیش نیاز های پروژه را نصب میکنیم
```bash
pip install -r requirements.txt
```

بعد از نصب پیش نیاز ها بک اند را اجرا میکنیم
```bash
python3 main.py
```
